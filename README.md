# TogoTechCensus (TTC) 🇹🇬

TogoTechCensus is a modern web application designed to map and showcase the technological landscape of Togo. It provides insights into tech projects, companies, and talent within the Togolese ecosystem.

## 🚀 Features

- **Project Showcase**: Explore innovative tech projects from Togo.
- **Ecosystem Monitoring**: Track the growth and trends of the Togolese tech scene.
- **Interactive Dashboards**: Visualize data through professional charts and maps.
- **Responsive Design**: Optimized for seamless experience across all devices.

## 🛠️ Tech Stack

- **Frontend**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Data Fetching**: [TanStack Query (React Query)](https://tanstack.com/query/latest)
- **Styling**: [Bootstrap 5](https://getbootstrap.com/)
- **Charts**: [Recharts](https://recharts.org/)
- **Animations**: [Lottie React](https://github.com/gamote/lottie-react)
- **State Management**: React Context / Hooks

## 📦 Getting Started

### Prerequisites

- Node.js (Latest LTS recommended)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/ovama/TogoTechCensus.git
   cd TogoTechCensus
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Environment Setup**
   Create a `.env` file in the root directory and add your configuration:
   ```env
   VITE_API_BASE_URL=your_api_url
   ```

4. **Start Development Server**
   ```bash
   npm run dev
   ```

## 🏗️ Project Structure

- `src/components`: UI components organized by feature (Home, Dashboard, etc.)
- `src/hooks`: Custom React hooks for business logic and data fetching.
- `src/assets`: Static assets like images and animations.
- `src/services`: API communication layer.
